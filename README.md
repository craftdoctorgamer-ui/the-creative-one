# The Creative One

A bold, editorial portfolio site for **The Creative One** — an independent creative studio / personal portfolio.

## Run locally

This is a dependency-free static site. Open `index.html` in a browser, or serve the folder with any static server:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`.

## Customize

- Replace the project names and descriptions in `index.html`.
- Update the email address and social links in the contact section.
- Adjust the palette and typography in `styles.css`.
- The abstract project artwork is built with CSS, so no image assets are required.

## Deploy

The site can be deployed directly with GitHub Pages, Netlify, Vercel, or any static hosting provider.
